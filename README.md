# Address Book

A simple **Address Book application developed in C** that allows users to store, manage, search, update, and delete contact information.

##  Project Description

The Address Book project is a menu-driven C application designed to manage contact details efficiently. It provides basic CRUD operations such as adding new contacts, searching for existing contacts, editing contact information, and deleting contacts.

This project helped me strengthen my understanding of **C programming, structures, functions, arrays, file handling, and data validation**.

##  Features

* Add a new contact
* Search for a contact
* Edit contact details
* Delete a contact
* Display all contacts
* Save contacts to a file
* Load contacts from a file
* Validate contact information
* Exit the application safely

##  Technologies Used

* **Programming Language:** C
* **Concepts:** Structures, Functions, Arrays, File Handling, Pointers
* **Compiler:** GCC
* **Development Environment:** VS Code / Linux

## ⚙️ Operations

### 1. Add Contact

Allows the user to enter and store contact information such as:

* Name
* Phone number
* Email address

### 2. Search Contact

Searches for a contact using available information such as name, phone number, or email.

### 3. Edit Contact

Allows existing contact information to be modified.

### 4. Delete Contact

Removes a selected contact from the address book.

### 5. Display Contacts

Displays all saved contacts in a structured format.

### 6. Save Contacts

Stores contact information in a file so that the data can be used later.

### 7. Load Contacts

Loads previously saved contacts when the application starts.

## ▶️ How to Compile

Open the project directory in a terminal and compile the source files using GCC:

```bash
gcc *.c -o addressbook
```

## ▶️ How to Run

### Linux / macOS

```bash
./addressbook
```

### Windows

```bash
addressbook.exe
```
